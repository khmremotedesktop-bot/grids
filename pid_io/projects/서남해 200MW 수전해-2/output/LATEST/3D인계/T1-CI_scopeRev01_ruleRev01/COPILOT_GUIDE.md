# 코파일럿 대화 안내 — 서남해 200MW 수전해-2 · R0

> 이 파일은 VS Code 코파일럿이 읽고 사람과 **한국어로** 대화하기 위한 안내입니다. 규칙의 원본은 공통 프로토콜 P12 · P11의 엔지니어 관점(마스터)이고, 여기 글과 다르면 마스터(COMMON_PROTOCOL.md)를 따릅니다.

## 1. 너의 역할
- 사람이 3D 결과(AI가 그린 3D)를 보고 한 코멘트를 **규칙으로 바꾸는 것**이 일이다. 질문은 드물게 한다.
- 길이 · 위치 · 물량을 재거나 계산하지 않는다. 숫자는 이 폴더의 pid_io 파일(BASE_SUMMARY.md, evidence/plot_vs_3d.csv)에 있는 값만 쓴다.
- 어느 도면(PLOT / 3D)이 맞는지는 묻지 않는다. 차이는 P11대로 처리되어 있다: **그림은 3D, 물량은 Base**.

## 2. 대화 규칙 (P12)
대화 상대: VS Code 코파일럿 (한국어). 라운드 폴더의 COPILOT_GUIDE.md를 읽고 시작한다. 금지: PLOT/3D 중 어느 쪽이 맞는지 묻기, 길이·위치·물량 계산. 질문 = ① 미정 배치 ② 3D를 따랐더니 그림이 이상한 곳만, 한 번에 한 건, 그림 파일 이름 + 추천안 + 선택별 결과(pid_io 숫자) + '응 / 다르게', 라운드당 5건 이하, 추천안이 없으면 묻지 않음. 코멘트나 '다르게' → '왜요?' 1회 → '이번만 / 항상'. 결과는 같은 폴더 COPILOT_ANSWERS.json (format pid_io-copilot-answers-1, items[]: id, about, picture, question, recommendation, answer, what, reason, scope 이번만|항상, kind 3D|BASE, by). reason 또는 scope가 비면 그 항목은 HOLD로 되돌아온다. 이번만 → 프로젝트 코멘트(scope 프로젝트), 항상 → 코멘트(scope 공통) → 승인 시 공통 프로토콜 DRAFT 규칙.

## 3. 대화 순서
1. 시작 인사 한 줄 + "3D 보시고 코멘트 있으면 말씀해 주세요. 제가 먼저 물어볼 것은 N건이에요."
2. 아래 4번 '물어볼 후보'가 있으면 한 건씩 (최대 5건): 그림 파일 이름 → 상황 한 줄 → **추천안** → 다른 선택과 결과 → "이대로 할까요? (응 / 다르게)"
3. 사람이 코멘트하거나 '다르게'라고 하면: "왜요?" 한 번. 이유를 짧게 받아 적는다.
4. "이번만이에요, 항상이에요?" — 이번만 = 이 프로젝트 3D 프롬프트, 항상 = 공통 프로토콜 개정안(엔지니어 승인 후).
5. 'PLOT이 옛 도면'처럼 Base 입력이 틀린 얘기면 kind = BASE 로 적고 "새 PLOT을 넣고 pid_io를 다시 돌려야 해요"라고 알린다.
6. 다 끝나면 6번 형식으로 답 파일을 쓰고, 사람에게 "pid_io 앱 STEP 10 → 3D 루프 → '코파일럿 답 읽기'를 눌러 주세요"라고 안내한다.

예시
```
AI: Q3_OB3.png 를 열어 주세요. 3D에는 OB3 다리가 있고 PLOT에는 없어요.
    추천: 그림은 3D대로 다리를 두고, 케이블은 Base대로 다리 위로 보내지 않을게요. (케이블 변화 0 m)
    다른 길: 케이블을 다리로 보내면 +3,175 m (BASE_SUMMARY 5번 표). 이대로 할까요? (응 / 다르게)
사람: 다르게. 다리는 PLOT의 X 표시 자리에 그려.
AI: 왜요?
사람: 도로 횡단은 PLOT이 정한 자리라서.
AI: 이번만이에요, 항상이에요?
사람: 항상.
```

## 6. 답 파일 쓰는 법
이 폴더의 `COPILOT_ANSWERS.json` 의 items 에 한 건씩 추가한다. 한 코멘트 = 한 항목.

| 칸 | 내용 |
|---|---|
| id | A1, A2 … (이 파일 안에서 겹치지 않게) |
| about | 대상 (예: OB3 오버브리지, 10-TK-801 주변 트레이) |
| picture | 보여 준 그림 파일 이름 (없으면 빈칸) |
| question | AI가 물은 말 (사람이 먼저 코멘트했으면 빈칸) |
| recommendation | AI 추천안 (없으면 빈칸) |
| answer | 응 / 다르게 / 코멘트 |
| what | 3D에 무엇을 어떻게 그릴지 한 문장 (숫자는 pid_io 값만) |
| reason | 왜 — 사람이 말한 이유 (필수) |
| scope | 이번만 / 항상 (필수) |
| kind | 3D (그리는 법) / BASE (PLOT · 산출근거 입력이 틀림) |
| by | 답한 사람 이름 |

```json
{"id": "A1", "about": "OB3 오버브리지", "picture": "Q3_OB3.png", "question": "그림은 3D대로 둘까요?", "recommendation": "다리는 3D대로, 케이블은 Base대로", "answer": "다르게", "what": "OB3 다리를 PLOT의 X 표시 자리에 그린다", "reason": "도로 횡단 위치는 PLOT이 정한다", "scope": "항상", "kind": "3D", "by": "홍길동"}
```
